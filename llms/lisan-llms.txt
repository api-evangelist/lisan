# Lisan

> Lisan is an AI-powered Arabic proofreading and writing-assistance platform. It detects and
> corrects eight classes of error (spelling, grammar, morphology, semantics, style, formatting,
> proper nouns, and citations), explains each correction so writers improve, and reports error
> statistics for individuals and institutions. Lisan is delivered as a web app, a Windows desktop
> app, Microsoft Word/PowerPoint/Outlook add-ins, Chrome and Edge browser extensions, a WordPress
> plugin, and — for institutional customers — an API and SDK.

Note: Lisan advertises an API and SDK for developers, but as of this writing publishes no public
developer portal, API reference, base URL, or specification. API access is arranged through the
institutional contact channel. No OpenAPI, SDK package, or public repository was found.

## Product

- [Proofreading](https://www.lisan.ai/proofreading): The eight error classes Lisan detects and corrects.
- [Language learning](https://www.lisan.ai/language-learning): Skill-building from correction explanations.
- [Extensions and platforms](https://www.lisan.ai/extensions): Word, PowerPoint, Outlook, Chrome, Edge, Windows app, WordPress, and the developer API/SDK listing.
- [For institutions](https://www.lisan.ai/institutional): Enterprise proofreading, institutional style-guide enforcement, and analytics dashboards.
- [Institutional features](https://www.lisan.ai/institutional-features): Detailed enterprise capability list.
